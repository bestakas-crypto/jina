1. 기술 스택
--------------------------------------------------------------------
- 순수 HTML / CSS / JS (프레임워크, 빌드 도구 없음)
- 데이터 저장: 브라우저 localStorage만 사용 (서버, 로그인, DB 없음)
- PWA: manifest.json + service-worker.js (홈 화면 설치, 오프라인 실행)
- 예외적으로 외부 API 1개 사용: 환율 자동 조회 (frankfurter.dev, 키 불필요, 무료)
- 배포: GitHub main 브랜치 push -> Vercel 자동 배포 (정적 호스팅, 빌드 단계 없음)

2. 지금 앱이 하는 일 (현재 기능 요약)
--------------------------------------------------------------------

[전체 컨셉]
자동매매가 아니라, 사람이 분할매수·분할매도 판단을 감정 없이 내리도록 돕는
시각적 도구. 종목을 자유롭게 등록해서 관리하는 "종목 등록형" 구조.

[화면 1] 종목 목록 (홈)
  - "+ 종목 추가" / "+ 예금 추가" 버튼으로 종목(이름/통화), 예금(계좌명/금액/통화) 등록
  - 종합 자산 요약 5줄: 매입금액 -> 평가금액 -> 예금총액 -> 총자산금액(=평가금액+
    예금총액) -> 손익(=평가금액-매입금액, 손익률%와 초록/빨강 색상). 전부 KRW/USD/JPY
    중 선택한 통화로 환산해서 표시
  - 현재가 미입력 종목, 환율 정보 없는 종목/예금은 각 합계에서 제외하고 몇 개(건)
    제외됐는지 안내 문구 표시
  - 합계 펼치기: 종목별 매입가+평가금액(이익=초록/손실=빨강), 예금별 원래 통화
    금액(배지)+표시통화 환산액
  - 펼치기 안에 환율 설정: 자동 조회 상태 표시, 통화별 환율 수동 수정/저장, 새로고침
    (종목·예금에서 쓰인 통화 전부 자동으로 대상에 포함됨)
  - 종목 카드: 신호등 아이콘, 종목명, 수익률(또는 "현재가 미입력"), 평균단가,
    보유수량, 매입금액, 카드 우측 상단 "⋮" 메뉴로 목록에서 바로 종목 삭제 가능
  - 카드 탭 -> 종목 상세로 이동
  - 예금 카드(종목 목록 아래 별도 섹션): 계좌명, 통화 배지, 예금액. "⋮" 메뉴로
    그 자리에서 바로 수정/삭제(별도 상세 화면 없음, 거래이력·ATR 등 종목용 로직 없음)

[화면 2] 종목 상세
  1. 보유 현황: 평균단가 / 보유수량 / 매입금액 / (현재가 입력 시) 평가손익·수익률
  2. 신호등 배너 (현재가 입력했을 때만, 5단계 중 하나, 이모지+문구로 색맹 사용자도
     구분 가능):
       🔴 매도 신호 도달 (손절선+익절 동시 충족)
       🔴 방어 매도 기준 도달 (추적 손절선 터치)
       🟠 익절 기준 도달
       🟢 매수 기준 도달
       🟡 관망 구간
  3. 오늘의 입력: 현재가 / ATR(14) / 보유 후 최고가(자동갱신 토글)
  4. 매매 기준 3줄: 다음 매수가 / 익절가 / 추적 손절선
     - 다음 매수가 = 직전 체결가 - (ATR x 매수배수)
     - 익절가 = 평균단가 + (ATR x 매도배수)
     - 추적 손절선 = 보유 후 최고가 - (ATR x 손절배수), 레칫 방식(한번 오르면
       다시 안 내려감)
  5. 보유 후 최고가 대비 하락 위치 한 줄 + "더보기"로 -5%~-30% 구간표
  6. 부분 매도 시뮬레이션: 10/20/30/50% + 직접 비율 입력, 수량·실현손익 미리보기
  7. 하단 고정 [매수 추가] [매도 추가] 버튼
  8. 거래 이력: 최근 5건 우선 표시(전체보기 가능), 행 탭하면 수정/삭제
     (수정·삭제 시 평균단가/보유수량/실현손익 전체 재계산)
  9. 종목 설정 (기본 접힘): 종목명/통화/매수·매도·손절 ATR배수/자동갱신 토글/
     종목 초기화/종목 삭제

[화면 3] 거래 입력 모달
  - 매수/매도 각각 날짜·단가·수량 입력, 저장 시점의 ATR을 함께 기록(atrAtExecution)

[헤더]
  - ← 뒤로가기 / → 앞으로가기 (브라우저 히스토리 기반, 실제 뒤로/앞으로 동작)
  - ⟳ 새로고침

[디자인]
  - 라이트 테마 (흰 배경 / 검은 글씨), 매수·이익 요소는 앰버/초록, 매도·손실
    요소는 틸/빨강, 숫자는 모노스페이스 폰트
  - 모든 금액 표시는 통화 단위(원/USD 등) 접미사 없이 숫자만 표시 (종목마다
    통화가 다를 수 있어서)

[데이터]
  - localStorage 키 "stock-portfolio" 하나에 전체 종목 배열 저장
  - 예금은 별도 키 "cash-deposits"에 배열로 저장 (종목 데이터와 독립)
  - 환율 정보는 별도 키 "fx-rates"에 저장 (자동조회 성공값 또는 수동입력값,
    선택한 표시통화 포함)
  - 기존 구버전(atr-grid:kospi, atr-grid:qqq) 데이터가 남아있으면 최초 실행 시
    감지해서 확인 팝업 후 새 구조로 자동 변환(거래 이력 보존)

4. 파일 구성
--------------------------------------------------------------------
  index.html         화면 마크업 (목록/상세/모달 전부 한 파일에)

  manifest.json        PWA 메타데이터

  icons/icon-192.png, icons/icon-512.png   PWA 아이콘
  history.txt          (이 파일) 개발 히스토리
